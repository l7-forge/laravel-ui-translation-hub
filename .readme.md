# Laravel UI Translation Hub


Ein schlankes, performantes Laravel-Volt Package zur Automatisierung und Verwaltung von UI-Skelett-Übersetzungen. Die Translation-Keys werden über ein Hex-Index-System (`bin2hex`) verwaltet, um saubere Blade-Templates und kollisionsfreie Keys zu garantieren.

## Features

- **Hex-Key-Indexierung**: Keine Probleme mit Sonderzeichen oder langen Texten in JSON-Keys.
- **Livewire Volt Integration**: Single-File-Component-Struktur für nahtlose UI-Integration.
- **Auto-Translate**: Einzelne Zeilen oder alle fehlenden Keys (`Translate All`) über die Server API übersetzen.
- **Dynamisches DB-Setup**: Automatische Erstellung der benötigten Sprachentabelle (`l7languages`).

## ⚙️ Core-Architektur: Wie der Hub im Hintergrund zaubert

Der **Laravel UI Translation Hub** ist nicht nur ein einfaches Interface – er bringt ein intelligentes, automatisiertes Ökosystem mit, das Entwicklern die gesamte Arbeit beim Erfassen von Übersetzungsschlüsseln abnimmt. 

Hier ist der technische Kern, der dieses Package so performant und wartungsarm macht:

### 1. Der magische `__t()`-Helper (Zero-Headache Keys)
Vergiss kryptische Arrayschlüssel wie `messages.welcome_subtext_admin`. Unser globaler Helper `__t()` nimmt den **echten Klartext** direkt aus deinem Blade-Skelett und indiziert ihn blitzschnell:

blade:
<h1>{{ __t('Willkommen auf unserem Marktplatz!') }}</h1>


## Installation

### 1. Repository einbinden & laden
Füge das Package in deiner `composer.json` hinzu oder lade es lokal über den Pfad.

composer require l7labs/-ui-translation-hub:@dev

### 2. Volt-Pfad Registrierung
Das Package registriert seine Volt-Komponenten automatisch über den `LaravelUiTranslationHubServiceProvider`. Es erweitert das bestehende App-Setup, ohne bestehende Pfade zu überschreiben.

### 3. language-switcher publishen 
php artisan vendor:publish --tag=l7-language-switcher --force
Blade-Tag:
    <livewire:l7-language-switcher />
    (sinnvoll im mainmenu um die sprache zu aendern, einfaches dropdown)

### 4. translation dashboard
php artisan vendor:publish --tag=l7-translator-dashboard --force
Blade-Tag:
    <livewire:l7-translator-dashboard />
    (Die power, du schreibst deine captions in deiner sprache, die legst du vorher als laravel base language im laravel .env an, APP_LOCALE=en), dann ist en Deine Base language, von der der Collector ausgeht, also collectet und indiziert, dann kannst du beliebig viele (gueltige) language ISOs hinzufuegen und als target language fuer eine uebersetzung angeben (z.b. de, fr, es)
    Im translation-dashboard werden jetzt alle fehlenden woerter / saetze deiner zielsprache angezeigt - du kannst sie jetzt direkt dort manuell uebersetzen, oder die translation-api unseres Servers verwenden.
    Wenn Du Dich das erste Mal anmeldest, bekommst Du ein freikontingent von 20000 zeichen, du kannst dann wie in einem prepaid paket neue Zeichenkontingente kaufen, und so deinen Kunden ganz einfach eine Sprache mehr in der UI anbieten, ohne dafuer jedes Mal das Rad neu erfinden zu muessen.

## Architektur & Funktionsweise

### Der Translation-Helper `__t`
Um die Templates sauber zu halten, verwendet das System einen Custom Helper, der die Konvertierung von Rohtext in den Hex-Key übernimmt und gleichzeitig als Kollektor fuer neue Spracheintrage agiert:


// In deiner App global registriert
function __t($text) {
    $hexKey = bin2hex($text); // Erzeugt den eindeutigen Key für das JSON
    // ... Translations-Logik
}
Verwendung im Blade-Template:
! Verwende einfach statt des originalen Laravel language translators diese syntax:
<h1>{{ __t('Willkommen auf unserem Marktplatz!') }}</h1>
Der Collector findet den string im ersten Seitenaufruf (im dev mode (!!) und listet ihn dann im translation-dashboard auf, wo du dann die zielsprache auswaehlen und entweder automatisch, oder manuel uebersetzen kannst)

Datenbank-Struktur:
Die Tabelle wird NUR fuer die verfuegbaren Sprachen verwendet.

Beim ersten Aufruf prüft das Package die Existenz der konfigurierten Tabelle (Standard: l7languages). Falls sie fehlt, wird sie mit folgender Struktur angelegt:SpalteTypBeschreibungidBIGINT (Primary)Eindeutige IDnameSTRINGKlartextname (z.B. "Spanish")codeSTRING (Unique)ISO-Code der Sprache (z.B. "es")statusTINYINT1 = Aktiv, 0 = Inaktiv
Achtung: Wenn die Tabelle dynamisch neu erzeugt wird, werden alte, nicht synchronisierte .json-Dateien im lang/-Verzeichnis sicherheitshalber bereinigt, um Daten-Inkonsistenzen zu vermeiden.


Was passiert im Hintergrund?

Der Helper konvertiert den Rohtext mittels bin2hex in einen absolut eindeutigen, kollisionsfreien Hexadezimal-Schlüssel.

Der Vorteil: 

1. Sonderzeichen, Zeilenumbrüche oder HTML im String brechen niemals das JSON-Format. Deine Blade-Templates bleiben lesbar und sauber.

2. Der integrierte Auto-Collector (Wachhund im Dev-Modus)
Du musst keine Übersetzungsdateien mehr händisch anlegen oder Keys eintippen. Das Package bringt einen vollautomatischen Collector mit:

Immer auf der Jagd: Sobald eine Seite im Browser aufgerufen wird (und sich die Anwendung im lokalen Entwicklungsmodus app.env !== 'production' befindet), scannt der Collector jeden gerenderten __t()-Aufruf.

Auto-Registrierung: Findet das System einen Hex-Key, der noch nicht in der Basis-Sprachdatei (config('app.fallback_locale')) existiert, wird dieser sofort und vollautomatisch in die entsprechende .json injiziert.

Produktions-Sicher: Im Live-Betrieb (production) schaltet sich dieser Collector komplett ab, um maximale Performance ohne Festplattenzugriffe zu garantieren.

3. High-Performance Caching (Schonend für den Server)
Weil das Auslesen und Dekodieren großer JSON-Dateien bei jedem Seitenaufruf wertvolle CPU-Zyklen kostet, greift das Package auf ein aggressives, aber smartes Caching-System zurück:

1-Klick-Invalidation: Jede geladene Sprache wird für volle 24 Stunden im Laravel-Cache gehalten (Cache::remember()).

Echtzeit-Aktualisierung: Sobald du im UI-Hub eine Übersetzung anpasst, einen Key übersetzt oder die Remote-API bemühst, wird der Cache für diese spezifische Sprache gezielt gelöscht (Cache::forget()).

Beim nächsten Seitenaufruf steht die neue Übersetzung ohne spürbare Verzögerung für deine Nutzer bereit.

4. Smart Visual Indicators (Visuelles Feedback für Entwickler)
Das System weiß genau, wann eine Übersetzung fehlt, und hilft dir beim Testen:

Ist die App auf eine Fremdsprache eingestellt (z. B. Spanisch es) und ein Text wurde im Hub noch nicht übersetzt, liefert der Provider automatisch den originalen Basistext mit einem angehängten Sternchen (*) zurück.

Du siehst sofort im Browser auf einen Blick, welche UI-Elemente noch übersetzt werden müssen, ohne ständig in den Hub schauen zu müssen!

public function setLocale($locale)

        session()->save(); // Make sure session is written immediadely

        
        return redirect('/');
    }
